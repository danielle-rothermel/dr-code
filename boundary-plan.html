Boundary Contract: Implementation Plan

dr-code · 2026-07-14
A new package, dr_code/trace, implements the contract from eval-flow-design: the artifact vocabulary, the Absent sentinel, the trace with reserved input/output keys, producer provenance, definition identity hashing, and lossless serialization. It depends only on pydantic and the stdlib, and is built first — the preprocessing and metrics plans both import it and never each other.

The contract package imports neither system.

  • dr_code.trace holds only the shared vocabulary; its imports are pydantic and the stdlib.
  • Preprocessing and metrics both import it downward; a test asserts it never imports humaneval, preprocessing, metrics, or synthetic.
  • This makes S1/S2 structural: the trace shape can only evolve here, deliberately.

What lives here — and what is kept out.

  • In: artifact types, Absent, Trace + reserved keys, TraceProducer, stable_hash, SerializedTrace, WiringError.
  • Out: steps, operators, records, runners, registries — those belong to the two systems.
  • Out: typed key bindings and binding layers — deliberately deferred until real usage reveals the shape (eval-flow L2).

FrozenModel is promoted to a shared base.

  • synthetic/models.py already defines the right config: frozen, extra=forbid, validate_assignment.
  • Move it to dr_code/models.py; synthetic imports it from there. One mechanical breaking edit, no shim.
  • All contract models — artifacts, producers, serialized traces, and both systems' definitions — subclass it, satisfying frozen, serializable, hashable definitions (M2).

In-flight values and persisted artifacts split by type system.

  • Per eval-flow L3: Trace is a frozen dataclass (in-flight, cheap, holds views-adjacent state later); SerializedTrace is a BaseModel (persistence, external schemas).
  • serialize_trace/deserialize_trace convert between them and are the only crossing point.

The placeholder dict contract gets a validated edge.

  • Values remain a flat namespace, but typed as Mapping[str, TraceValue] where TraceValue = Artifact | Absent — parse at the boundary instead of carrying dict[str, Any] inward.
  • JsonArtifact is the escape hatch for externally built traces (e.g. a HumanEval task payload); consumers revalidate it at bind time.
  • The sharp runtime distinction lives here: missing key ⇒ WiringError (incompatible definitions), present-but-Absent ⇒ data.

The artifact union is the versioned part of the contract.

  • Adding an artifact kind is additive — old payloads still parse.
  • Changing an existing kind's fields is a boundary change: bump TRACE_SCHEMA_VERSION and state the migration.
  • Derived views (ASTs) are module functions, never fields — serialization loses warm caches, never information (S3).

TraceValue = Artifact | Absent


class WiringError(Exception):
    """Incompatible definitions: missing key, wrong artifact kind, or invalid
    settings. Raised at bind time — before any input is processed — and never
    per-input (eval-flow L2). Both systems raise this same type.
    """


@dataclass(frozen=True, slots=True)
class Trace:
    values: Mapping[str, TraceValue]     # flat namespace; must contain input & output
    producer: TraceProducer
    step_facts: Mapping[str, Mapping[str, str]] = field(default_factory=dict)
    # step_facts: provenance recorded by steps (chosen alternative, rejection
    # reasons, candidate counts) keyed by instance name — facts, never judgments (P-L2)

    def __post_init__(self) -> None:
        """Validate RESERVED_KEYS ⊆ values; reject non-TraceValue entries."""

    def value(self, key: str) -> TraceValue:
        """Missing key raises WiringError. Present-but-Absent returns the
        Absent value — callers decide what not-applicable means for them.
        """

Implementation order & considerations

#DeliverableContentsProof it works
1FrozenModel promotion Create dr_code/models.py; update the three synthetic imports. Existing synthetic test suite passes unchanged.
2Artifacts + Absent artifacts.py, absent.py; discriminated union round-trips through JSON. Union parse/dump tests; unknown-kind payload rejected.
3Provenance + identity provenance.py, identity.py. Golden-hash test (stable across runs and field order).
4Trace + WiringError trace.py with reserved-key validation and external_trace. Missing-key raises WiringError; Absent returns as data; reserved keys enforced.
5Serialization serialization.py + schema version. Property test: serialize → deserialize → serialize is byte-equal.
6Façade + hygiene Curated __init__.py; dependency-direction test. __all__ curation test; no upward imports (grep-style test).

Do not build the typed binding layer yet.

  • Eval-flow L2 marks the flat namespace as an intentional placeholder; adding typed views now would guess at usage the design says to wait for.
  • The compensations that are in scope: TraceValue validation at construction, WiringError at bind time, and Absent as data.

JsonArtifact needs discipline, not machinery.

  • It exists so external producers can put non-vocabulary values (a task record) in a trace without breaking serialization totality.
  • Rule: consumers revalidate into their own model at bind time and never reach into payload raw. Enforced by review, documented on the class.

Cross-plan dependencies.

  • This package blocks all of the preprocessing plan and steps 1+ of the metrics plan; it is one small PR — build it first.
  • The metrics milestone 0 (task.py split) has no dependency on this package and can proceed in parallel.
  • Freeze this package's surface before the other two plans land; later changes are versioned boundary changes, not refactors.
